En classe

Pour les enseignants

Attribuez des exercices en une minute et voyez qui les a réussis. Une application pour la classe, l’atelier ou le travail individuel.

Ce que vous obtenez en tant qu’enseignant

🏫

Classes et code

Des classes de 2.A à 9.F. Les élèves se connectent avec un code que vous pouvez afficher en plein écran au projecteur.

📌

Attribution d’exercices

Attribuez des exercices à toute la classe ou à des élèves précis, avec une date limite et une remarque.

📊

Suivi de la progression

Étoiles, points, exercices réussis, points forts et faibles, et dernière activité de chaque élève.

🌟

Différenciation

Aux élèves à haut potentiel, vous attribuez des exercices d’une classe supérieure ou du monde des olympiades.

👨‍👩‍👧

Accès parent

Chaque élève a un code parent en lecture seule : le parent voit la progression de son enfant.

🛟

Assistance

Le bouton 💬 directement dans l’application : signalez une erreur ou envoyez une idée.

Démarrer en 10 minutes

  1. Obtenez un compte. Les comptes enseignants sont créés par l’administrateur de l’application (e-mail et mot de passe). Pour l’instant, nous les attribuons au cas par cas ; écrivez-nous via l’icône 💬 dans l’application.
  2. Créez une classe. Dans l’espace enseignant, choisissez la classe et la lettre (par ex. 4.B). Vous obtenez un code de classe.
  3. Affichez le code au projecteur. Le bouton « Code en plein écran » affiche un code géant. Les élèves le saisissent dans Profil → Se connecter à l’enseignant.
  4. Attribuez des exercices. Choisissez des exercices dans les niveaux ou dans la collection, sélectionnez toute la classe ou des élèves précis, fixez une date limite.
  5. Suivez la progression. Dans l’aperçu, vous voyez qui a terminé et qui n’a pas commencé. Vous pouvez exporter les résultats en CSV.

Idées d’utilisation

⏱️

Échauffement de 5 minutes

Au début du cours, les élèves résolvent un exercice d’un niveau. Une activation rapide de la réflexion.

🎒

Devoirs au choix

Vous attribuez 3 à 5 exercices, les élèves les résolvent à leur rythme et vous voyez l’avancement.

🏆

Une ligue de classe

Grâce aux étoiles et aux exercices réussis dans l’aperçu, vous pouvez organiser un concours entre classes ou groupes.

🎯

Préparation aux concours

Entraînement aux types de réflexion avant la Pythagoriade, le Kangourou et l’Olympiade.

Déploiement sur les appareils

  • iPad / Android sans installation depuis un magasin. L’application fonctionne dans le navigateur et peut être ajoutée à l’écran d’accueil.
  • Gestion des appareils (par ex. Jamf). Avec un profil de configuration de type Web Clip, vous pouvez envoyer le lien de l’application à tous les appareils en une fois.
  • Réseau de l’école. Autorisez l’adresse de l’application et du serveur dans le filtre web. Après le premier chargement, elle fonctionne aussi hors ligne.
  • Données des élèves. Nous enregistrons uniquement le pseudo, la classe et la progression. Les détails sont sur la page Questions et données.

Envie d’essayer LogiQ en classe ?

Écrivez-nous via l’icône 💬 dans l’application. Nous serons ravis de vous aider pour la configuration et d’écouter vos remarques. Pendant la phase pilote, l’utilisation est gratuite.
